简历收集与入库
HR 日常持续操作
多渠道收集简历 → 上传至CV库 → 系统自动+手动打标签 → 去重检查 → 状态设为"待筛选"
📄 简历文件 → CV库存储
2
用人需求发布与审批
BU Head 人事部 Jenny
填写聘用员工申请表 → 人事部确认(编制+预算) → Jenny终审 → 发布 → 系统自动匹配CV库 三级审批
📋 《HRT-000-2022 聘用员工申请表》
3
简历匹配与初筛
HR
根据岗位标签从CV库检索 → 多标签组合筛选 → 关键词全文搜索 → 生成候选人短名单 → 标记"已推荐"
🔍 候选人短名单
4
HR一面
HR
发送面试通知 → 面试 → 填写一面评估 → 通过则系统自动触发求职申请表（发送免登录链接给面试者）
不通过 → 标记"人才储备"
📝 一面评估记录 + 触发求职申请表链接
5
求职申请表填写
面试者 免登录·专属链接
点击专属链接 → 填写基本信息(姓名/联系方式/教育/工作经历/技能/期望薪资等) → 电子签名 → 提交
📋 《HRP-001-2023 求职申请表》· 板块一
6
部门二面
BU Head
系统发送求职申请表+二面通知 → BU Head查看基本信息 → 安排面试 → 填写二面评价(通过/不通过/待定) → 结果自动同步HR
📋 《HRP-001-2023 求职申请表》· 板块二(二面)
7
董事终面
董事/老板
系统发送求职申请表+终面通知 → 查看前两轮评价 → 面试 → 给出最终结论(录用/不录用) → 结果同步HR+BU Head
📋 《HRP-001-2023 求职申请表》· 板块二(终面)
8
综合评估与录用审批
BU Head 人事部 Jenny
三方评估汇总 → BU Head填写录用审批单(岗位/薪资/入职日期/合同类型) → 三级签字 → 审批完成 审批完成→方可盖章用印
📋 《HRP-001-2023 求职申请表》· 板块三(录用审批单) ─ 此为唯一审批载体
9
入职谈话
HR 系统·腾讯会议
HR选择时间 → 系统自动预约腾讯会议 → 短信通知面试者 → 线上谈话(确认到岗日期/薪资福利/合同) → HR填写纪要
🎥 腾讯会议记录 + 谈话纪要
10
Offer发送
HR 系统·公司邮箱
HR选择模板 → 系统生成录用通知书PDF → 设定回复时效(默认X小时) → 公司公共邮箱自动发送 → 状态"Offer待回复"
📧 《HRT-003-2020 录用通知书》 PDF
11
Offer追踪
系统自动
定时轮询邮箱 → 智能识别回复(接受/拒绝) → 接受→通知HR启动入职 | 拒绝→流程结束 | 超时→"已过期"可延期重发 → 临近截止自动提醒
🤖 邮件回复 + 语义识别
12
🚀 入职准备交接
HR 流程进入入职管理模块
Offer被接收 → 系统自动通知HR → 启动入职准备：入职引导表、行政安排(门禁/HKMS/工位)、合同准备、钉钉入职、培训通知
📦 流程交接至入职管理模块 → 产品说明书第五章
